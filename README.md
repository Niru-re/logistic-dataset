# Logistic Dataset

A collection of datasets and supporting code for food-freshness detection,
quality grading, cold-chain logistics, and related machine-learning projects.

## Contents

| Path | Description |
|------|-------------|
| `dynamic_supply_chain_logistics_dataset.csv` | Supply-chain logistics tabular dataset |
| `fruit_quality/` | Fruit quality data |
| `vegetable_quality/` | Vegetable quality data |
| `cold_chain/` | Cold-chain / shipment data |
| `Fruits-Vegetables-Dataset-main/` | Fruits & vegetables image dataset |
| `Fruits-And-Vegetables-Detection-Dataset-main/` | Fruits & vegetables detection dataset (YOLO labels) |
| `Door Open-Close.v1i.yolov8/` | Door open/close YOLOv8 dataset |
| `prepared/` | Processed / ready dataset phases |
| `trained_models/` | Trained model artifacts |
| `6639009_map_doc_india/` | Map document (India) |
| `Food-Expiry-Days-Prediction-Using-Machine-learning-main/` | Food-expiry prediction project |
| `external_sources/` | External references |

## Excluded (kept locally)

The following large image datasets exceed GitHub's practical push limits and are
intentionally **not** included in this repository:

- `fruits_360/` (~8 GB)
- `healty_&_rotten/` (~4.9 GB)

They remain available locally and can be added later via Git LFS or GitHub Releases.
